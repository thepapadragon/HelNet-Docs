// MODULES

Modular by Design

All modules are off by default. Enable exactly what your server needs via /setup modules. Each module operates independently.

Time Module
Deploy a live timezone terminal into any channel. Members set their UTC offset and DST preference — the terminal automatically displays every member's local time. Includes inline time suggestions via chat commands.
TERMINAL + SUGGESTIONSView Guide →
Division Module
Create and manage in-server divisions (squads, factions, units). Members join and leave through a self-service terminal. Supports primary and secondary division roles, welcome messages, and per-division branding.
ROLES + TERMINAL + WIZARDView Guide →
Announcement Module
Create reusable announcement presets with custom headers, footers, accent colors, and ping roles. Post polished, branded briefings in seconds with /announcement send. Edit within 48 hours if needed.
PRESETS + BRANDINGView Guide →
InfoPost Module
Let designated roles post and edit styled messages directly through HelNet. Keep server information channels clean and consistent without needing admin access.
STYLED POSTSView Guide →
DEIMOS Module
Community-driven spambot detection. Every member is an Enforcer. Flag a suspected bot with /deimos kill — two others must confirm within 5 minutes. Confirmed kills result in a 14-day mute and message purge.
ANTI-SPAM + NETWORKView Guide →
Challenges Module
Create and manage server challenges with flexible frequency controls i.e. daily, weekly, monthly, or all-time. Members submit proof, managers grade submissions as Passed or Failed with a click.
CHALLENGES + GRADINGView Guide →
// SETUP PROTOCOL

Getting Started

Follow these steps to get HelNet operational in your server. Initial setup takes under 5 minutes.

01
Add HelNet to Your Server

Click the button below to invite HelNet. The link requests all permissions needed to operate every module.

+ Invite HelNet
02
Configure Your Server

Run /setup server to set your server's accent color. This color will be applied to embed borders throughout HelNet.

03
Enable Modules

Run /setup modules to toggle features on or off. All modules are disabled by default — only enable what you need.

04
Configure Each Module

Each enabled module has its own setup commands. Check the guides below for per-module configuration steps.

HELNET // SETUP SEQUENCE
helnet@server:~$ /setup server
↳ Server Color: #00FF00 applied
helnet@server:~$ /setup modules
↳ [✓] Time Module — ENABLED
↳ [✓] Division Module — ENABLED
↳ [ ] Announcement Module — OFF
↳ [ ] DEIMOS Module — OFF
// All changes take effect immediately. No restart required.

DEIMOS Module

Community-driven spambot detection. No single moderator can act alone — it takes the collective to confirm a kill.

Kill Vote Flow

Member spots bot
→
/deimos kill @user
→
Kill Vote appears
→
2 members confirm
within 300 seconds
→
14-day mute
+ message purge

When a moderator bans via the kill report, a DEIMOS Network Alert is broadcast to every server running DEIMOS. Other admins can preemptively ban the flagged user before they arrive.

Cannot flag bots, mods, or admins
Cannot confirm your own kill vote
One active vote per target at a time
1-minute cooldown between kill votes
Reversed kills count as −1 for all voters
Scoring tracked on /deimos killboard
