Privacy Policy

Last updated: May 2026

Overview

HelNet is committed to being transparent about what data it accesses and stores. This policy explains what information HelNet collects when operating in your Discord server.

Data We Access

To function, HelNet may access the following information provided by Discord:

  • Discord user IDs and usernames (for command attribution and role management)
  • Server (guild) IDs and channel IDs (for configuration and output targeting)
  • Message content in channels where commands are invoked

Data We Store

HelNet stores only the configuration and data necessary to provide its features:

  • Server-specific settings (roles, channels, module configuration)
  • Challenge submissions and completion records
  • Division and announcement data created by server staff

We do not sell, share, or use this data for any purpose outside of operating HelNet's features.

Data Retention

Server data is retained for as long as HelNet remains in your server. Removing HelNet from your server will result in your server's configuration and stored data being deleted.

Third Parties

HelNet does not share data with third parties. All data remains within the HelNet system and is used solely to provide bot functionality.

Contact

For privacy-related questions, join the HelNet Support Server.
