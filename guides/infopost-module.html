InfoPost Module

Styled messages posted and edited through HelNet

The InfoPost Module lets designated members post styled messages through HelNet — formatted with an accent color, optional image, optional title, and author credit. Posts can be edited in-place without deleting and reposting.

Who Can Post

By default, members with Manage Messages permission can use /message send. Admins can also configure specific roles that are allowed to post via /message wizard.

Posting a Message

Run /message send in any text channel. A form opens with:

  • Title (optional) — displayed as a large header in the embed
  • Content (required, markdown supported) — the body of the post
  • Image (optional) — displayed at the top of the post

The post appears styled with the server's accent color and credited to your username.

Editing a Post

1
Open the context menu

Right-click (or long-press on mobile) on any InfoPost message.

2
Apps → Message Edit

Select HelNet from the Apps submenu, then Message Edit.

3
Update and submit

The form opens pre-filled with the current title, content, and an option to replace the image. Submitting updates the post in place — no new message is created. The original author credit is preserved.

Only posts sent through /message send can be edited this way.

Commands

/message send

Post a styled info message in the current channel.

Requires: Manage Messages, or a configured role
/message wizard

Configure which roles can post, and set the accent color for posts.

Requires: Administrator
